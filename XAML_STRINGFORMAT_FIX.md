# WinUI XAML StringFormat build fix

Fixed `MainWindow.xaml` build error WMC0011:

`Unknown member 'StringFormat' on element 'Binding'`

WinUI 3 does not support WPF-style `Binding.StringFormat`. The TX trace status binding is now a plain binding:

```xml
<TextBlock Text="{Binding ControllerTxTracePath}" ... />
```

The `TX trace:` prefix is generated by `MainViewModel.ControllerTxTracePath` instead.

No controller timing, UDP send tracing, polling cadence, or qualification behavior was changed.
